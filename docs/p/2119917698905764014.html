[UI] SaaS 대시보드 우측 알림 패널 디자인 — @zahragr8r

  • 워크플로 자동화 대시보드 오른쪽에 알림 패널을 고정 — 본문(지표·워크플로 표)을 가리지 않고 나란히 확인
  • 패널 상단에 All / Errors / Success / Info 필터 탭, 각 알림은 상태 점 + 제목 + 한 줄 설명 + 시간 + 상태 배지 구조
  • 실패(Error)·성공 배지를 색으로 구분해 훑어보기만으로 문제 알림을 찾을 수 있음
  • 적용 아이디어: 백오피스 알림은 모달·드롭다운보다 '본문 옆 고정 패널 + 상태 필터 탭' 구조가 작업 흐름을 덜 끊음
