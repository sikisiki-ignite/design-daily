[AI] AI가 만든 UI가 다 비슷해 보일 때 — 프로덕트 디자인용 무료 스킬 8선 — @rpnickson

  • 모델 기본값으로 만들면 결과물이 비슷해지는 문제를, 작업 전에 불러오는 지침 묶음(스킬)으로 해결하자는 정리
  • 여러 디자인 방향을 나란히 비교(Oil UI), UI 애니메이션 원칙(Emil Kowalski), 레이아웃·밀도 조절(Taste), 'AI 티' 제거(Impeccable) 등
  • 어워즈 수상 사이트를 레퍼런스로 끌어오는 Awwwards MCP처럼, 지침이 아니라 '도구'를 붙이는 방식도 함께 소개
  • 적용 아이디어: 팀 디자인 원칙(간격·밀도·모션 규칙)을 스킬 형태 문서로 만들어 두면 AI 결과물의 일관성을 잡는 데 바로 쓸 수 있음
관련 링크
  • Oil UI — 서로 다른 디자인 방향 여러 개를 나란히 비교
  • Impeccable — AI 티 나는 UI 다듬기
  • Emil Kowalski skills — UI 애니메이션 원칙
  • Taste Skill — 레이아웃 다양성·모션·밀도 조절
  • Stageshow — 제품 데모 애니메이션·벤토 그리드
  • Dimensional Drawing — 컴포넌트 스펙 도면
  • Brand Identity skill — 로고·타입·컬러를 한 시스템으로
  • Awwwards MCP — 수상작 레퍼런스 수집 도구
