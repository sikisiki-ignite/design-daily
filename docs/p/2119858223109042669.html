[UI] 여행 기록 앱 — '+' 하나에서 펼쳐지는 생성 바텀시트와 지도 화면 — @UxDamini_

  • 하단 탭 가운데 '+' 버튼을 누르면 '새 여행 / 기록 추가 / 장소 추가 / 컬렉션 만들기'를 한 바텀시트에서 고르게 구성
  • 각 선택지에 일러스트 아이콘 + 한 줄 설명을 붙여 무엇을 만드는지 바로 이해되게 함
  • 지도 화면은 장소 사진을 핀으로 올리고, 상단 필터 칩(All·Visited·Saved·Food)으로 범위를 좁힘
  • 적용 아이디어: 만들 수 있는 게 여러 종류인 서비스는 '생성 버튼 1개 + 종류 선택 시트' 구조로 진입점을 하나로 모을 수 있음
