[Motion] iOS 27 글래스 버튼이 메뉴로 '변신'하는 전환 — @_Kavsoft

  • SwiftUI에서 matchedTransitionSource를 glass 스타일보다 먼저 붙이면, 버튼이 따로 뜨는 팝오버가 아니라 버튼 자체가 늘어나 메뉴가 되는 전환으로 바뀜
  • Before/After를 같은 화면에서 비교: Before는 메뉴가 버튼 위에 별도로 나타나고, After는 우하단 + 버튼에서 메뉴가 자라나듯 펼쳐짐
  • 트리거 요소와 결과 요소를 하나의 덩어리로 이어주는 shared element 전환이 시스템 기본 메뉴 수준으로 쉬워짐
  • 적용 아이디어: FAB·더보기 버튼에서 열리는 메뉴는 '어디서 나왔는지' 보이도록 출발점에서 확장되는 전환을 기본값으로 고려
