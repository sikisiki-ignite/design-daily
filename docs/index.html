[AI] 아이콘 제작 과정을 100% 코드로 만든 31초 모션 필름 — @marcelkargul
  • Figma 스토리보드 6프레임(가이드선 → 치수 → 외곽선 → 채움 → 디테일 → 완성) → SVG 15개 레이어로 분리 → Remotion으로 레이어별 타이밍 애니메이션
  • 선이 스스로 그려지고, 라벨은 캐럿과 함께 한 글자씩 타이핑, 채움은 미세한 점이 모여 완성되는 연출
  • CSS 3D로 기울어진 평면 + 낮은 매크로 카메라 + 얕은 피사계심도, 9컷 하드컷 편집. 수정은 '전체 28% 빠르게'처럼 수치로 지시
  • 적용 아이디어: 제품 소개·릴리즈 영상을 Figma 스토리보드 → 코드 렌더링 파이프라인으로 만들면 수정이 '수치 변경'이 되어 반복이 빨라짐

[UI] 여행 앱 Roam — 빈 상태(Empty state)를 장면으로 만든 모션 — @Wuraoladesigns
  • 'No trips yet' 빈 상태에 줄에 걸린 폴라로이드 사진 3장을 배치 — 비어 있는 화면이 '첫 여행이 걸릴 자리'라는 이야기로 바뀜
  • 주 행동(Plan a trip, 오렌지)과 보조 행동(Find ideas, 회색)을 나란히 두어 다음 행동을 명확히 함
  • 아래에는 가로 스크롤 '인기 여행지' 카드로 빈 상태에서도 탐색 거리를 제공
  • 적용 아이디어: 목록이 비어 있는 화면에 '안내 문구 + 1차 행동 + 둘러볼 거리' 3단 구성을 기본 패턴으로 정리

[UI] SaaS 대시보드 우측 알림 패널 디자인 — @zahragr8r
  • 워크플로 자동화 대시보드 오른쪽에 알림 패널을 고정 — 본문(지표·워크플로 표)을 가리지 않고 나란히 확인
  • 패널 상단에 All / Errors / Success / Info 필터 탭, 각 알림은 상태 점 + 제목 + 한 줄 설명 + 시간 + 상태 배지 구조
  • 실패(Error)·성공 배지를 색으로 구분해 훑어보기만으로 문제 알림을 찾을 수 있음
  • 적용 아이디어: 백오피스 알림은 모달·드롭다운보다 '본문 옆 고정 패널 + 상태 필터 탭' 구조가 작업 흐름을 덜 끊음
#dashboard #notification #saas #panel
